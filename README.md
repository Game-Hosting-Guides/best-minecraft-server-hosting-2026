## How we rank

Scores weight the things that actually determine whether a server runs well, not marketing bullet points:

1. **CPU disclosure & single-thread performance** — the biggest lever for TPS. Hosts that name their silicon rank higher than equivalent hosts that hide it.
2. **Datacenter coverage** — latency is set by distance to your players; a great CPU in the wrong region still feels bad.
3. **Real RAM & storage** — honest allocations on NVMe, not oversold shared memory.
4. **Backups, panel, and modpack support** — recoverability and day-to-day usability.
5. **Honest pricing** — the true entry cost, not a promo rate that resets on renewal.
